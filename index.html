Factory

Drop a text. Get a reader.

Any language in · any language out

Paste a poem, shloka, or short passage — or drop a file, or a URL. The factory detects the source language, builds a two-column reader, and speaks each original word as you hover. Translation defaults to English. About the first 2,000 tokens are used.

Keys stay in this browser tab or in the local server environment. They are never committed. Run python3 factory_server.py for URL fetching and to keep the key off the page.
